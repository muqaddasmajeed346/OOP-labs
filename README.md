C++ Object-Oriented Programming Labs

Introduction

This repository contains my C++ Object-Oriented Programming (OOP) lab work completed throughout the semester. The labs focus on understanding and implementing fundamental and advanced OOP concepts through practical programming exercises.

Topics Covered:

- Classes and Objects
- Data Hiding and Encapsulation
- Constructors and Destructors
- Inheritance
- Polymorphism
- Function Overloading
- Operator Overloading
- Friend Functions
- Static Members
- Abstract Classes
- Pure Virtual Functions
- Templates
- File Handling
- Exception Handling

Objectives

The main objectives of these labs are to:

- Develop a strong understanding of Object-Oriented Programming
- Apply OOP principles in real-world scenarios
- Improve problem-solving and programming skills
- Write reusable and maintainable C++ code

Technologies Used

- C++
- Dev-C++ / Code::Blocks
- Standard Template Library (STL)

Key Learning Outcomes

By completing these labs, I learned how to:

- Design programs using classes and objects
- Implement inheritance and polymorphism
- Use templates for generic programming
- Manage files using file handling techniques
- Build modular and scalable applications

Academic Purpose

This repository is maintained for educational and learning purposes as part of the Object-Oriented Programming course.
